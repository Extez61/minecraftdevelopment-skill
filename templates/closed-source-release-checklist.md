# Closed-source release checklist

- Ownership/distribution rights, exact tool version/license and supported bytecode:
- Target game/server/Java/Kotlin/build pipeline:
- Entry points/public API/reflection/resources/serialization keep inventory:
- Profile by package; hot paths excluded from expensive transformations:
- Commands/permissions/stable save IDs and external contracts preserved:
- Before/after artifact/startup/MSPT/latency/allocation evidence:
- Final protected JAR runtime/integration/restart tests:
- Private build ID, mapping/retrace and reproducibility evidence:
- No source/maps/secrets/unauthorized third-party code in distribution:
- Licensing outage/privacy/non-destructive failure policy, if applicable:
- Authorized local analysis assessment and explicit gaps:

Do not generate a permanent checklist for an unrelated small task. This is not a claim of AI-proof code or zero-overhead obfuscation.
