# Security

Do not report credentials, player data, exploit details or private logs in public issues. For a sensitive report, use GitHub private vulnerability reporting if the repository enables it; otherwise contact the repository owner through an existing trusted private channel. No response-time or supported-version guarantee is implied.

Review downloaded skill instructions and scripts before installing or executing them. A skill is guidance, not a security sandbox. Use native client installation or reviewed folder copying; no Python installation scripts are bundled.

For this private repository, use your authorized Git connection and native plugin installation or direct folder copying. Never put tokens in URLs, command arguments, Markdown or support messages.
