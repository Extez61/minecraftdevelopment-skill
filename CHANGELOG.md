# Changelog

## 1.0.0 — Initial release

- Six English Java/Kotlin Minecraft skills: core development, Fabric, Paper, Bukkit/Spigot, NeoForge and server operations.
- Version-specific engineering guidance for Minecraft Java 1.21.1–26.2, behavior preservation, optimization, testing and migration.
- Server configuration, profiling, players, permissions, backups, maintenance and safe remote-management guidance.
- Defensive anti-cheat, API integrations, mod-list inspection and optional companion-skill workflows.
- On-demand AI navigation, concise user-facing responses and token-conscious retrieval.
- Owned closed-source plugin protection guidance, reflection/metadata keep rules and measured performance acceptance.
- Claude Code plugin/marketplace metadata; Git/native plugin installation, direct folder-copy guidance and supported coding-client adapters.
- Consolidated installation-first README and agent-facing INSTALL.md; private GitHub access, publishing, CI and release-file validation.
- Optional developer tests and read-only inspection tools; no Python dependency for skill installation. Live game/client/provider integrations remain untested as described in QA.md.

Initial publication version is 1.0.0. Earlier package iterations were development drafts, not published releases. No GitHub release or tag has been created by packaging.
